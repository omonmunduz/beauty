# Как всё устроено и что делать — простыми словами

## 1. Что это такое

Одна платформа онлайн-записи для многих салонов.

```
              ┌──────────── ОДИН общий домен (например zapis.kg) ────────────┐
              │   zapis.kg/ventura      zapis.kg/salon-2      zapis.kg/...    │
              └───────────────────────────┬───────────────────────────────────┘
                                          │  (Cloudflare Pages — сайт)
                                          ▼
                         ┌──────── ОДНА база (Supabase) ────────┐
                         │ салоны · услуги · мастера · записи   │
                         │ каждый салон видит только своё       │
                         └──────────────────────────────────────┘
```

- **Сайт** один на всех. Салон отличается только окончанием ссылки.
- **База** одна на всех. Защита на уровне базы: владелец салона A физически не может прочитать записи салона B.
- **Салон** = папка `tenants/<имя>/` (файл `business.json` + фото) → команда публикации → ссылка готова.

### Путь клиентки
1. Открывает ссылку → видит фото, цены, мастеров, адрес.
2. «Записаться» → услуга → дата и время (занятое перечёркнуто) → имя и телефон. Без регистрации.
3. Видит свою запись, может отменить по правилам салона, добавить в календарь, включить напоминание.
4. Может спросить помощника: «Когда ближайшее окно?», «Сколько стоит…?».

### Путь владельца салона
1. Входит в кабинет `…/ventura/owner` по почте и паролю (выдаём мы).
2. Видит записи на день/неделю, отмечает «Пришла»/«Готово», вносит оплату.
3. Статистика: визиты, выполнено, сколько денег реально получено.
4. Сам меняет цены, мастеров, график, фото.

## 2. Жизненный цикл салона

```
 мы делаем демо ──► отправляем ссылку ──┬─► салон купил ──► «Запустить» ──► работает, платит подписку
 (статус preview,                       │
  жёлтая плашка «демо»)                 └─► молчит 14 дней ──► АВТОМАТИЧЕСКИ в архив
                                                              (ссылка «Студия не найдена»,
                                                               демо-записи удалены)
```

- **Домен при этом не трогается** — он общий для всех салонов. Удаляется только салон.
- Демо-режим: записи помечены как тестовые, уведомления не уходят.
- Запущенный салон (live) в архив сам не уходит никогда.

### Команды (`prod:` — облако, `tenant:` — локально)

| Что сделать | Команда |
|---|---|
| Список всех салонов и сроков демо | `pnpm prod:status` |
| Продлить демо на 7 дней | `pnpm prod:extend ventura --days 7` |
| Скрыть салон сейчас (можно вернуть) | `pnpm prod:archive ventura` |
| Вернуть из архива | `pnpm prod:restore ventura` |
| Удалить навсегда | `pnpm prod:delete ventura --confirm ventura` |

## 3. Домен: .kg или .com

Нужен **один** домен на всю платформу. Покупается один раз, продлевается раз в год.

| | .kg | .com |
|---|---|---|
| Доверие у клиентов в КР | выше — «местный» | нормальное |
| Где купить | у регистратора зоны .kg (ищите «регистрация домена .kg») | Cloudflare Registrar — по себестоимости, прямо в аккаунте Cloudflare |
| Подключение к сайту | купить у регистратора → в его панели указать DNS-серверы Cloudflare | в 2 клика, всё внутри Cloudflare |
| Если будете работать и в других странах | хуже | лучше |

**Совет:** если работаете только в Кыргызстане — `.kg` (звучит солиднее для местных салонов). Если планируете Казахстан/Россию/Узбекистан — `.com`. Название — короткое и про запись: `zapis`, `bron`, `beautybook` и т.п. Цены и правила регистрации проверяйте на сайте регистратора на дату покупки.

### Как подключить купленный домен (когда купите — сделаю сам)
1. Добавить домен в Cloudflare (Websites → Add a domain).
2. Если домен куплен не в Cloudflare — у регистратора заменить DNS-серверы на те, что покажет Cloudflare (обычно до 24 часов).
3. Cloudflare Pages → проект `beauty-booking` → Custom domains → добавить домен.
4. Ссылки салонов станут `ваш-домен/s/ventura/`.

## 4. Салон сказал «классно, покупаю» — что делать по шагам

**День 1 — сбор данных (15–20 минут разговора или анкета в WhatsApp):**
- [ ] Точный адрес + как найти вход, ссылка на 2ГИС/Яндекс-карты
- [ ] График работы и выходные
- [ ] Список услуг: точные цены и **сколько длится** каждая процедура
- [ ] Мастера: имя, специализация, фото (по желанию), какие услуги делает каждый
- [ ] 5–10 своих фото + логотип
- [ ] Правило отмены (за сколько часов можно отменить онлайн)
- [ ] Почта владельца для входа в кабинет

**День 1 — настройка (10 минут у нас):**
1. Внести данные в `tenants/ventura/business.json`, фото — в `tenants/ventura/images/`.
2. `pnpm tenant:check ventura` — проверка, что всё заполнено правильно.
3. `pnpm prod:publish ventura` — обновить салон в облаке (записи сохраняются).
4. `pnpm prod:owner ventura почта@владельца` — выдать доступ, пароль показывается один раз → отправить владельцу лично.
5. `pnpm deploy:cloudflare` — обновить сайт (нужно, если поменялись фото/иконки).

**День 1 — запуск вместе с владельцем:**
6. Владелец входит в кабинет, всё смотрит, при желании правит цены/мастеров сам.
7. В кабинете: Настройки → Запуск → «Запустить студию». Демо-записи удаляются, включаются напоминания, автоархив отключается.

**После запуска:**
8. Ссылку — в шапку Instagram, в автоответ WhatsApp, в карточку 2ГИС.
9. Через неделю — созвон: всё ли удобно, сколько записей пришло.
10. Оплата — подписка раз в месяц (см. ниже). Если не оплатили — `pnpm prod:archive ventura`, после оплаты — `pnpm prod:restore` + запуск.

## 5. Деньги

**Расходы платформы (на всех салонов сразу, не на каждого):**
- Cloudflare Pages — бесплатно (коммерция разрешена)
- Supabase — бесплатно на старте; для живых салонов нужен Pro ≈ $25/мес (бесплатный проект засыпает после недели без активности)
- Домен — раз в год
- ИИ-помощник — по факту использования, есть суточный лимит; без ключа работает упрощённо и бесплатно

**Доход — предлагаемая модель (проверить на первых 5–10 салонах):**
- 14 дней бесплатно после запуска
- Подписка в месяц, зависит от числа мастеров (1–2 / 3–5 / 6+)
- Разовые платные опции: свой домен салона, оформление фото, перенос клиентской базы

## 6. Что пока сделано не до конца (честно)

- Длительности процедур Ventura, график, адрес и мастера — **предположения**, уточнить у салона.
- Фото Ventura — стоковые (бесплатные, без авторских ограничений), их Instagram-фото мы не брали без разрешения.
- ИИ-помощник без ключа LLM отвечает в упрощённом режиме (но по реальным данным).
- Push-уведомления на реальном телефоне ещё не проверены.
